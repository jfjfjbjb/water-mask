# 水印相机

一款简洁高效的在线水印添加工具，支持为图片添加时间、地点等水印信息。

## 功能特性

- **批量上传**：支持一次性上传多张图片
- **实时预览**：左侧选择图片，右侧即时预览水印效果
- **灵活缩放**：通过滑块调整水印大小（0.2x - 2.5x）
- **一键下载**：将带水印图片导出为 JPG 格式

## 技术栈

- React 19 + TypeScript
- Vite (rolldown-vite)
- Ant Design 6
- Less

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
